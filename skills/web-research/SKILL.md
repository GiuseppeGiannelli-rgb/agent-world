# Web research

## Loop
1. Write 3–5 search queries from different angles (definition, numbers, competitors, criticism, recent news).
2. `web_search` each one; open only the 2–3 most promising results with `web_fetch`.
3. Cross-check every number with a second source; when sources disagree, say so.
4. For tools and libraries, read the GitHub repository (stars, last update, README) and look for Reddit or Hacker News discussions about real use.

## Notes format
- **Summary**: 3 bullets a busy reader needs.
- **Findings**: grouped by theme, each with its source link.
- **Open questions**: what you could not verify.
- **Sources**: list of URLs with one line each on why they are trustworthy.

## Rules
- Never invent a source or a number. If you could not find it, write that.
- Prefer primary sources (official docs, filings, papers) over aggregators.
- Note the date of time-sensitive facts.
